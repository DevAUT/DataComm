Results provenance

reference_results.csv contains 37 experiment rows generated by
scripts/reference_simulator.py, a deterministic event-driven reference
model that mirrors the intended ARQ state machines and point-to-point
serialization/propagation assumptions. It is included only to provide
preview tables and plots because this build environment has no
Docker/ns-3 runtime.

It is not an ns-3 trace or ns-3 measurement. After running
scratch/arq-hw3.cc in the course-provided ns-3 Docker image, save the
authoritative results as ns3_results.csv, then regenerate the plots and
recompile report.tex.
