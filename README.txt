ns-3 Homework 3 — Flow Control and Reliable Transmission
========================================================

PROJECT CONTENTS
----------------
scratch/arq-hw3.cc             ns-3 C++ implementation of Stop-and-Wait,
                               Go-Back-N, and Selective Repeat.
scripts/plot_results.py        Generates assignment plots from an ns-3 CSV.
scripts/reference_simulator.py Separate discrete-event preview model. It is
                               NOT ns-3 and must not be reported as ns-3 data.
results/reference_results.csv  Preview data from the reference model only.
plots/                         Preview plots from reference_results.csv.
report.tex                     Persian XeLaTeX report. Its current numeric
                               tables and figures are preview/reference data;
                               update them from the real ns-3 CSV before final
                               submission.

The C++ simulation uses exactly two nodes and one point-to-point link. It
implements custom DATA/ACK headers directly above PointToPointNetDevice; it
does not use Wi-Fi, IP, UDP, or TCP for the ARQ protocols.

GITHUB CODESPACES: BUILD NS-3.46
--------------------------------
These steps assume your Codespace is running Ubuntu 24.04 and that this
project's files are in /workspaces/DataComm.

1. Install the ns-3 build dependencies (skip packages already installed):

   sudo apt-get update
   sudo apt-get install -y build-essential g++ python3 cmake ninja-build \
       git pkg-config sqlite3 libsqlite3-dev libxml2-dev libgsl-dev \
       python3-matplotlib python3-numpy python3-pandas

2. Download the exact ns-3 release used by this project:

   cd /workspaces
   git clone --depth 1 --branch ns-3.46 \
       https://gitlab.com/nsnam/ns-3-dev.git ns-3-dev

3. Configure and build ns-3:

   cd /workspaces/ns-3-dev
   ./ns3 configure --build-profile=optimized
   ./ns3 build -j2

4. Copy the assignment program into ns-3's scratch directory:

   cp /workspaces/DataComm/scratch/arq-hw3.cc scratch/arq-hw3.cc

5. Run all 37 required experiment configurations:

   mkdir -p /workspaces/DataComm/results
   ./ns3 run "arq-hw3 --mode=all --outFile=/workspaces/DataComm/results/ns3_results.csv"

The actual ns-3 output will be written to:

   /workspaces/DataComm/results/ns3_results.csv

The run includes:
- Problem 1(a): Stop-and-Wait, one-way delays 1, 5, and 20 ms.
- Problem 1(b): Stop-and-Wait, p = 0, 0.01, 0.05, 0.10, 0.20.
- Problem 2(a): Go-Back-N, W = 1, 2, 4, 8, 16, 32 at 5 and 20 ms.
- Problem 3(a): Go-Back-N and Selective Repeat, p = 0.05, all six windows.
- Problem 3(b): Selective Repeat, W = 32, receive-buffer capacities 4, 8,
  16, 32, and 64 packets.

CUSTOM RUN
----------
Example of one configurable Selective Repeat run:

   cd /workspaces/ns-3-dev
   ./ns3 run "arq-hw3 --mode=single --protocol=sr --delayMs=5 --loss=0.05 --window=32 --bufferCapacity=20 --timeoutMs=100 --seed=12345 --outFile=/workspaces/DataComm/results/custom.csv"

Command-line parameters include: mode, protocol, rateMbps, delayMs,
simulationSeconds, timeoutMs, loss, payloadBytes, window, bufferCapacity,
seed, and outFile.

PLOTS FROM REAL NS-3 RESULTS
----------------------------
The Codespace already has the Python plotting packages installed. Run:

   cd /workspaces/DataComm
   python3 scripts/plot_results.py results/ns3_results.csv \
       --outdir plots --source-label "ns-3.46"

PERSIAN LATEX REPORT
--------------------
The report uses XeLaTeX, xepersian, and the Amiri font. If the TeX packages
are not installed in the Codespace, install them with:

   sudo apt-get update
   sudo apt-get install -y texlive-xetex texlive-latex-extra \
       texlive-lang-arabic fonts-hosny-amiri

Then compile from the project directory:

   cd /workspaces/DataComm
   xelatex -interaction=nonstopmode -halt-on-error report.tex
   xelatex -interaction=nonstopmode -halt-on-error report.tex

IMPORTANT: Regenerating the plots does not automatically replace the
reference numbers in the report's tables. The current report clearly labels
its preview data as reference-model output, not ns-3 measurements. After the
real ns3_results.csv exists, update the report tables and discussion from
that CSV before submitting. Do not claim the preview CSV or preview plots
were generated by ns-3.

EXPERIMENT ASSUMPTIONS
----------------------
Default settings: 10 Mbps point-to-point link; 5 ms one-way propagation
delay; 1000-byte DATA payload; 30-second observation; 20-packet default
Selective Repeat out-of-order receive buffer; 100 ms ARQ timeout; fixed seed
12345; saturated sender. DATA and ACK frames are independently subject to
the same configured loss probability. Goodput counts only unique payload
bits delivered in order. Retransmission ratio is retransmitted DATA frames
divided by unique DATA payloads delivered. Receiver peak occupancy counts
only out-of-order packets buffered by Selective Repeat.

Selective Repeat buffer overflow policy: an out-of-order DATA frame is
dropped without ACK when the finite receiver buffer is full; the sender
retries after that packet's timer expires. The receiver delivers in-order
packets immediately and drains any now-contiguous buffered packets.
